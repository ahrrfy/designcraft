# استكمال الكتاب من داخل البرنامج — AI19

يعالج هذا التحديث انقطاع مسار الاستكمال بين المستند المفتوح وواجهة الإنتاج. يبقى اعتماد الصفحات قراراً بشرياً منفصلاً عن بدء الإنتاج وإعادة المحاولة.

- تعرض الواجهة زر استكمال للكتاب المختار وعدد صفحاته المتبقية. يحافظ الاختصار على التعليمات والنموذج والإعدادات الحالية. خيار تحرير المستند الحالي موضح كمهمة تحرير مستقلة، وليس مجموعة صفحات كتاب.
- يحفظ المضيف آخر طلب إنتاج صالح في `AI/production-draft.json` داخل ملف التشغيل الخاص. تستعاد التعليمات والإعدادات بعد التشغيل دون مفاتيح أو عامل تشغيل أو اعتماد. لا تحفظ التعليمات في `ui.json`. معرف المستند يمحى عند الاستعادة لأنه خاص بالجلسة؛ اختيار الكتاب أو تجهيز الاستكمال مطلوب قبل بدء طلب جديد.
- يراجع المضيف تغييرات التحديد والتنقل محلياً: إذا بقي تخصيص المستند الأصلي والخطوط والتفضيلات كما هو، يحدث رقم الحالة دون إضاعة مراجعات الصفحات. تغيير التصميم الفعلي لا يمر بهذا المسار ولا يطلق طلباً مدفوعاً.
- يظهر زر فتح مستند البروفة عند الانتقال إلى تبويب آخر. يعيد اختيار المستند الصحيح فقط، ولا يسجل مراجعة أو اعتماداً. تبقى بصمات البروف وإصدار المستند وفعل المستخدم شروطاً للاعتماد.
- تحتفظ المحاولة الفاشلة الحية بسجل الاستهلاك والمهارات المثبتة. تعيد محاولة صريحة الصفحات التي لم تنشر فقط، وتستخدم حدود المهمة الأصلية واستهلاكها المتراكم. لا تسمح بإعادة محاولة تتجاوز صفحات منشورة أو تغيّر عدد الصفحات أو تكتب فوق محتوى جديد. بعد إعادة تشغيل البرنامج لا يستعاد هذا التفويض؛ يبدأ المستخدم مهمة استكمال جديدة بعد مراجعة الكتاب.
- يحصل المخطط على مستطيل الهوامش الآمن المحسوب وجهة الصفحة والتجليد. يمكن تصحيح موقع إطار نص جديد بتحريك محسوب دون تغيير كلماته أو حجم الخط أو أبعاده، بشرط عدم الاصطدام بالنصوص أو الصور أو العناصر الموروثة. ترفض الحالات الملتبسة، وتظل التغييرات على النسخة الخاصة حتى اكتمال الفحص.
- يوضح فهرس الأوامر نوع نتيجة كل أداة. تفحص المراجع إلى نتائج الأوامر السابقة قبل التنفيذ، ولا تعامل نتيجة التنسيق كمعرف إطار أو قصة نصية. عند طلب تصحيح مدفوع يرسل رد المخطط الأصلي، لا أوامر المضيف الموسعة التي قد تفسد المراجع وربط النسخ.

تغطي اختبارات الانحدار استعادة التعليمات دون تشغيل، استمرار الرصيد عند إعادة المحاولة، بقاء الصفحات السابقة، عدم تجاوز الاعتماد البشري، الرجوع إلى مستند البروفة، والتحريك المحلي الآمن. تبقى مراجعة صحة الرسوم والأعداد والمحتوى التعليمي والبروفة الطباعية مطلوبة؛ نجاح التنفيذ لا يثبت جودة منهج ناشر أو مطابقة رسومه.
