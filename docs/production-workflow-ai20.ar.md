# تشغيل الإنتاج واستكمال المستند — AI20

تتبع هذه المرحلة إصلاحات [استكمال الكتاب AI19](production-continuation-ai19.ar.md). يبقى المستخدم صاحب اختيار المستند وعدد صفحاته وحجم مجموعة المراجعة؛ تقسيم طلبات النموذج داخلي ولا يمنح اعتماداً للانتقال إلى مجموعة أخرى.

## مسار الاستخدام

1. افتح الكتاب واختره من قائمة المستند المستهدف، ثم اختر استكمال الصفحات المتبقية. تحرير المستند الحالي عملية تحرير مستقلة.
2. اكتب المطلوب أو راجع التعليمات المستعادة، واختر المزود والنموذج. تعرض نتيجة اكتشاف النماذج قائمة قابلة للاختيار ما دام المزود وعنوانه مطابقين، حتى بعد تحديث الحالة أو اختيار نموذج آخر منها.
3. حدد صفحات المراجعة. يظهر تقدير محافظ للطلبات للنصوص العادية وللسكربتات ذات الصفحات المرقمة؛ الصور وفحصها البصري مخصصات تقديرية وليست استهلاكاً مؤكداً. زيادة حد الطلبات زر صريح، ولا تغير الواجهة ميزانية المستخدم أو عدد صفحات مراجعته تلقائياً.
4. ابدأ الإنتاج. بعد الفشل استخدم إعادة محاولة المجموعة للمهمة الحية إذا أردت الاحتفاظ بسجلها التراكمي ومهاراتها المثبتة. بدء إنتاج جديد ينشئ مهمة وسجلاً جديدين؛ استعادة التعليمات بعد إعادة التشغيل لا تعيد تفويض المهمة القديمة.
5. راجع كل صفحة وبروفتها ثم اعتمد المجموعة بنفسك. عرض المستند أو تغيير التحديد لا يعد اعتماداً، ولا يطلق طلبات إضافية.

## المقاسات والتجليد والسياق

- يحافظ الاستكمال على مقاسات المستند المفتوح؛ مقاس ملف النمط لا يعيد تحجيمه. إذا ذكر السكربت مقاس قص صريحاً يتعارض مع الكتاب، يرفض الطلب قبل إطلاق العامل ويطلب اختيار المستند أو تصحيح المقاس. تبقى الصفحات السابقة محمية، ويقتصر الاستكمال على لاحقة فارغة متصلة بعد صفحات مكتملة.
- تعرض واجهة إنشاء الصفحات المتقابلة اتجاه فتح تلقائياً أو اختياراً صريحاً من اليمين إلى اليسار أو بالعكس. يعرض الكتاب المتقابل المفتوح تجليده الحقيقي للقراءة فقط أثناء الاستكمال. تعديل المستند الحالي لا يغير إعدادات تجليده من لوحة الذكاء.
- تعيد كل مجموعة بناء قائمة الخطوط المتاحة وأسماء الألوان وسياق الطباعة واتجاه الصفحات وموقع ذاكرة التخزين المؤقت. تنقل ملخصات محدودة للمحتوى السابق مع أحدث عناصره؛ لا ترسل أول المستند كاملاً كل مرة ولا تتعامل مع مجموعة فاشلة باعتبارها صفحات معتمدة.
- عند بدء استكمال جديد بلا تاريخ موافقات حي، تستعمل الصفحات السابقة كملاحظات عن محتوى موجود، دون اختلاق موافقات بشرية سابقة.

## توافق القوالب

يشترك اقتراح عائلات الصفحات والمترجم في فحص القوالب ذات العدادات غير المرتبطة بالمعطيات. لا يقترح المخطط قالباً سيرفضه المترجم، ولا تستبدل الكميات التعليمية بقيم نموذجية ثابتة. تبقى صفحة افتتاح نمو النباتات في الصفحة الأولى الفعلية فقط؛ لا تتكرر بسبب دورة توزيع الصفحات. تستخدم التعبيرات الرقمية اللاتينية اتجاه LTR مع الاحتفاظ بمحاذاتها وتنسيقها الأصليين.

مسار تصدير حزمة المهارة مستقل عن مسار حفظ أو تصدير المستند، ويبدأ افتراضياً بـ `skill-package.zip`. كلا الحقلين خاص بجلسة الواجهة ولا ينقلان مفاتيح المزودين إلى التفضيلات أو المستودع.

## حدود التحقق

اختبارات الانحدار تفصل بين صحة تنفيذ الأوامر، سلامة المستند، وتقدير الاستهلاك. نجاحها لا يثبت صحة عدد الأشياء داخل صورة مولدة، أو صلاحية المنهج تربوياً، أو مطابقة إنتاج ناشر. تبقى البروفة البصرية والتعليمية البشرية مطلوبة. تحفظ نتائج الفحص والتجربة المحلية تحت `outputs/continuation-repair-20261021/` دون تضمين مفاتيح.
