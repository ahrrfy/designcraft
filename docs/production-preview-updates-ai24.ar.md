# التزامن المستمر وتحديث النسخة المحلية — AI24 / AI25

تعرض لوحة الإنتاج إصدار البرنامج ورقم مصدر النسخة وحالة التحديث. زر «فحص وتجهيز التحديث» مستقل عن مزودي الذكاء، ويعمل في الخلفية دون إغلاق المستندات أو استئناف الإنتاج أو اعتماد البروفات. تظهر أخطاء الاتصال كما هي؛ لا تعني نتيجة الاتصال الفاشلة أن النسخة محدثة.

يتزامن فرعنا `ahrrfy/designcraft` دورياً كل 6 ساعات مع المستودع الرسمي الأصلي `storytold/designcraft` عبر مسار `upstream-sync.yml`، حيث تُدمج التزامات المصدر الأصلي وتُفحص عبر بوابات الجودة الكاملة قبل دمجها في `main` ونشر إصدار `v*-ai*` تلقائياً. كما ينشر مسار `windows-preview.yml` إصداراً موثقاً تلقائياً عقب كل فحص `Rust CI` ناجح على `main`. يستقبل المشغل هذه التحديثات المنشورة من `ahrrfy/designcraft` فقط مع التحقق من إثبات الفحص وسلسلة النسب الأمامية؛ إذ إن تثبيت نسخة upstream مباشرة دون دمج قد يزيل إضافات التصميم الذكي.

يمكن تفعيل الفحص التلقائي الدوري في الخلفية على ويندوز عبر `Install-PreviewUpdateScheduledTask` في `start-native-preview.ps1`، الذي يسجل مهمة مجدولة للمستخدم (`Smart Design Auto Update` كل ساعتين، ومهمة `Smart Design Upstream Sync` كل 6 ساعات عبر `sync-upstream-local.ps1` لضمان استمرار المزامنة والنشر حتى عند توقف GitHub Actions مؤقتاً) لتجهيز التحديثات الموثقة أو ترقيتها للتشغيل القادم دون مقاطعة العمل.

عند وجود برنامج مفتوح، تُحفظ بيانات النسخة المجهزة بشكل ذري بجانب مؤشر النسخة الحالية. يبقى البرنامج المفتوح وملفاته ومجلد إعداداته ومهاراته ومخزن مفاتيحه المحمي كما هي. تظهر رسالة بالحفظ والإغلاق وإعادة الفتح عبر المشغل؛ لا ينفذ الزر أو المهمة المجدولة إغلاقاً إجبارياً.

عند التشغيل التالي، يعيد المشغل التحقق من بصمتي التطبيق وأداة CLI ورقم المصدر قبل تفعيل النسخة المجهزة. يمنع التلف أو النقص التفعيل دون تغيير المؤشر الحالي. تبقى النسخة السابقة للاستعادة. فحص `ValidateOnly` للقراءة فقط، ولا يثبت تحديثاً أو يبدأ طلباً مدفوعاً.

هذه تجربة تحديث تلقائية تحافظ على قناة برنامجنا وإضافاته العربية والذكائية كاملة، بينما يبقى اختصار `ArtCraft Launcher` الرسمي المثبت منفصلاً تماماً ولا يُستبدل.
