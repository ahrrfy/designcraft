# تحديث النسخة المحلية — AI24

تعرض لوحة الإنتاج إصدار البرنامج ورقم مصدر النسخة وحالة التحديث. زر «فحص وتجهيز التحديث» مستقل عن مزودي الذكاء، ويعمل في الخلفية دون إغلاق المستندات أو استئناف الإنتاج أو اعتماد البروفات. تظهر أخطاء الاتصال كما هي؛ لا تعني نتيجة الاتصال الفاشلة أن النسخة محدثة.

يستقبل المشغل تحديثات فرعنا المنشورة من `ahrrfy/designcraft` بعد نجاح فحوصات المصدر نفسه. تدخل إصلاحات المصدر الأصلي عبر الدمج والفحص في المستودع؛ تثبيت نسخة upstream فوق البرنامج مباشرة قد يزيل إضافاتنا، لذلك لا يستخدمها مسار التحديث.

عند وجود برنامج مفتوح، تُحفظ بيانات النسخة المجهزة بشكل ذري بجانب مؤشر النسخة الحالية. يبقى البرنامج المفتوح وملفاته ومجلد إعداداته ومهاراته ومخزن مفاتيحه المحمي كما هي. تظهر رسالة بالحفظ والإغلاق وإعادة الفتح عبر المشغل؛ لا ينفذ الزر إغلاقاً إجبارياً.

عند التشغيل التالي، يعيد المشغل التحقق من بصمتي التطبيق وأداة CLI ورقم المصدر قبل تفعيل النسخة المجهزة. يمنع التلف أو النقص التفعيل دون تغيير المؤشر الحالي. تبقى النسخة السابقة للاستعادة. فحص `ValidateOnly` للقراءة فقط، ولا يثبت تحديثاً أو يبدأ طلباً مدفوعاً.

هذه تجربة تحديث شبيهة بمشغل ArtCraft الذي حدده المستخدم، لكنها تحتفظ بقناة برنامجنا وإضافاته. اختصار ArtCraft المثبت منفصل ولا يُستبدل. نجاح اختبارات التحديث الاصطناعية لا يعني وجود إصدار أحدث منشور؛ يظهر الزر النتيجة الفعلية للمصدر عند الفحص.
