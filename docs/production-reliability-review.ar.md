# مراجعة موثوقية الإنتاج وجودة الإخراج — AI17

## نتيجة الفحص

المحرك ينفذ الأوامر على مستند خاص قبل النشر، ويثبت إصدارات المهارات، وينشر مجموعة المراجعة كوحدة قابلة للتراجع. هذه ضوابط تنفيذ مهمة، لكنها لا تقيس صحة المنهج أو جودة التصميم البصرية.

ظهرت فجوتان في مسار القوالب: رفض النص بسبب تقدير عدد المحارف قبل قياسه داخل الإطار، وشراء صور جزء مبكر قبل التأكد من نصوص الأجزاء التالية في مجموعة المراجعة. سجل الخطأ السابق يجمع المفقود والفارغ والطويل برسالة واحدة ولا يحفظ الرد المرفوض؛ لذلك لا يثبت أي سبب منها وقع في تلك الاستجابة تحديداً.

## إصلاحات هذا التحديث

- يصبح `max_chars` هدفاً لاختصار النسخة للمخطط. يبقى حد حماية مستقل قدره 4096 محرفاً لكل حقل وحد JSON المحدود. يفصل التشخيص الصفحة والعائلة والحقل وسبب الرفض. لا يُقتطع النص أو التشكيل ولا يُصغّر الخط أو يُكبّر الإطار خفية. يقرر التنضيد الأصلي صلاحية النص، ويبقى التجاوز الحقيقي مرفوضاً قبل طلب الصور.
- تُخطط نصوص جميع أجزاء مجموعة المراجعة وتُركّب وتُفحص محلياً أولاً. ثم يُفحص قبول مجموعة طلبات الصور المخططة ضمن الرصيد نفسه قبل شراء أول صورة. تأتي مرحلة الصور والبروف بعد ذلك. تظل النتيجة خاصة إلى اكتمال المجموعة، ويبقى الانتقال للمجموعة التالية بقرار الإنسان.
- لا يُفعّل التصحيح المدفوع ولا تُعدّل حدود المستخدم أو مفاتيحه نتيجة هذا الإصلاح. يبقى النص الفارغ أو المفقود خطأً صريحاً، بدلاً من ملئه بكلام مخترع.

تؤكد [وثائق Gemini](https://ai.google.dev/gemini-api/docs/structured-output) أن حدود `minLength` و`maxLength` لا تُفرض أثناء التوليد، وأن التحقق المحلي مطلوب. تحويل الطلب إلى JSON منظم وحده لا يعالج ملاءمة النص الطباعية.

## التحسينات التالية بحسب الأولوية

| الأولوية | التحسين المقترح | أثره ومعيار قبوله |
|---|---|---|
| عالية | سجل استئناف محلي للأجزاء الصحيحة | حفظ المحتوى والخطة والأصول ببصمات البرومبت والنمط وإصدارات المهارات والهندسة والنموذج. إعادة المحاولة تعيد استخدام الأجزاء المطابقة فقط، ولا تعيد شراء صورة سليمة. لا يجيز الاستئناف تجاوز حاجز المراجعة أو نشر جزء ناقص. |
| عالية | تقدير تشغيل قبل البدء | عرض عدد طلبات النص والصور الداخلية وسبب التقسيم، وفحص توافق العدد مع حدود الطلبات والرموز والتكلفة. السقف المالي المفتوح لا يلغي حد عدد الطلبات؛ يجب إظهار أثره على الكتاب كله. |
| عالية | إظهار إنذارات الطباعة في تقرير كل مجموعة | تقرير المجموعات يبدأ حالياً بقائمة ملاحظات فارغة ولا ينقل كل إنذارات `preflight` إلى التقرير. الدقة المنخفضة إنذار وليست بالضرورة خطأً حاجباً. يلزم عرض PPI الفعلي والخطوط والألوان، مع إعداد جودة طباعة صريح، دون الادعاء بضمان 300 PPI من نجاح الفحص وحده. |
| عالية | مطابقة البرومبت بالقوالب قبل التوليد | ربط كل متطلب بصفحة وحقل أو منطقة محتوى. القالب ذو حقول ثابتة لا يستوعب تلقائياً أي نص تعليمي طويل. تُكشف المتطلبات غير الممثلة ويُختار توزيع مناسب قبل الإنفاق، بدلاً من ضغط وصف صفحة كاملة في صندوق قاعدة صغير. |
| متوسطة | فصل التعليمات المشتركة عن نص كل صفحة | حفظ سجل متطلبات كامل، وإرسال القواعد المشتركة والصفحات الجاري تنفيذها مع سياق الاستمرارية اللازم. يجب اختبار عدم سقوط أي متطلب؛ لا يُلخّص البرومبت أو يُحذف منه شيء خفية. قياس التوفير يسبق أي وعد بنسبة محددة. |
| متوسطة | تنويع التوزيع بحسب النشاط | المهارات المساعدة توجه المحتوى، لكنها لا تعيد رسم قوالب هندسية ثابتة. نحتاج عائلات مناسبة للمقارنة والتسلسل والاستقصاء والقصة والتصنيف والكتابة، مع فحص التكرار بين الصفحات وربط الاختيار بهدف التعلم. |
| متوسطة | تفسير اختيار المهارات تلقائياً | عرض المهارات المستخدمة وأسباب اختيارها في التفاصيل مع إبقاء النمط الأساسي واحداً. الاختيار الحالي يعتمد على كلمات تعريف محلية، وقد يستدعي مهارة بسبب ذكر عابر في برومبت طويل؛ لا يمثل تدريباً لأوزان النموذج. |
| متوسطة | حزمة هوية مصورة أصلية | لوحة شخصيات وألوان وإضاءة ومراجع رسوم أصلية متسقة، تمرر لمزود الصور عند دعمه. النص والهيدر والفوتر ومساحات الإجابة تبقى عناصر أصلية؛ الصورة داخل إطار قابل للتحرير والاستبدال، وليست تفاصيلها الداخلية عناصر فيكتور. |

## بروتوكول اختبار الجودة والإنتاجية

1. استخدام حالات عربية وإنجليزية ومشكولة، مع أطوال متفاوتة، ومراجعات بعدد 2 و12 صفحة، واستكمال مستند موجود دون تعديل الصفحات السابقة.
2. قياس اكتمال المتطلبات والتدرج التعليمي وصحة المحتوى وتنوع الأنشطة، ثم الهوية والتوازن والمساحات والمحاذاة والقراءة. فحص التنضيد وحده لا يختبر هذه الصفات.
3. اختبار فشل جزء لاحق، والإلغاء، وحدود الطلبات والرموز والمال، وعدم شراء صور قبل صلاحية النصوص، وعدم نشر مستند جزئي أو الانتقال دون اعتماد صريح.
4. قياس الرموز التي يعيدها المزود، والتكلفة المقدرة، والوقت حتى قبول التصميم، وعدد التصحيحات البشرية. المقارنة تستخدم البرومبت والنموذج والأسعار والمهارات نفسها.
5. فحص الملف الأصلي والتحرير والتراجع، وPDF والخطوط المضمنة والألوان والدقة الفعلية. قبول العينة بصرياً وتربوياً يظل بشرياً؛ لا توجد نسبة تشابه مقاسة مع ناشر في هذه الاختبارات.

## حدود التحقق

اختبارات الإصلاح محلية وبمزودات اصطناعية، وتثبت منطق التنفيذ والمحاذير دون طلبات مدفوعة. العينة العربية المحلية ذات 68 محرفاً اجتازت إطاراً 165×62 نقطة بخط Tahoma Bold بحجم 12 وتباعد 17 نقطة دون أخطاء أو إنذارات. هذه عينة لملاءمة النص وليست صفحة منهج مكتملة أو إثباتاً لسبب استجابة Gemini السابقة.
