# Native visual composition

Translate the brief into a compact visual system: audience, learning outcomes, tone, page geometry, columns, gutters, type roles, colors and image treatment. Respect the user’s exact requirements. Preserve the identity across pages while varying the composition to suit content.

Choose a layout per page: comparison, matching cards, ordered process, illustrated explanation, observation journal or mixed activity. A page may contain several related subtopics, activities and independent photographs. Neither one picture nor one topic per page is a default requirement. Use a single large image only when the brief or teaching purpose benefits from it. For ages 5–6, group related information clearly and keep each instruction short; teacher review decides suitability.

Use native text frames, paths, shapes, labels, rules and drawing areas. Give each illustration its own frame and each caption its own editable text frame. Request realistic photo assets separately when asked; preserve native headers, footers, page numbers, vocabulary and activity marks. Use native vector drawing for genuinely editable diagrams and marking tasks. Build original artwork and visual grammar; do not reproduce publisher pages or claim curriculum equivalence.

The sample shows two picture slots and an activity zone; these are layout placeholders, not an instruction to generate outline-only artwork. In real production the image provider supplies each requested photo. Adapt the number and dimensions to the brief, current provider limits, page count and remaining task budget.
