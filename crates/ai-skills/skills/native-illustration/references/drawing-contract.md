# Native drawing contract

Paths use anchors with p, optional in/out Bézier handles, and closed. Consult production.catalog for exact current schemas. Coordinates and stroke weights are in points. Use an explicit spread on each creation and result references for later fill, stroke and labels.

Choose image count and section count from the actual brief, not a fixed per-page rule. Use multiple editable figures for sequences, comparisons or activity panels. The program's resource and command limits still apply.

Keep each caption in a native text frame with explicit font, size, leading, direction and alignment. Verify the complete private draft and rendered proof. Never erase hidden text or claim that a raster has become editable vector artwork.
