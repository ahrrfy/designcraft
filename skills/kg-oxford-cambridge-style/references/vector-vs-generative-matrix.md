# Vector vs. Generative Modality Matrix

- **Generative Image Slots (`image_slots`)**: Cover hero art, syllabus banner icons, isolated hardware/vocabulary flashcards, 4-panel story/lab scenes, reading portraits, and hands-on project scenes. Always request NO text, NO letters, NO speech bubbles inside pixels.
- **Native Decomposable Vectors (`object.group`)**: Unit headers, ribbons, speech bubbles, IPO system flowcharts (`Input -> Process -> Output`), 4-line staves, CPA ten-frames, part-whole bonds, crossword grids, and classification shapes.
