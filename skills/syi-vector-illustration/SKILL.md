Choose the smallest route: create from a compact plan, preserve/edit existing geometry, or reconstruct an actually inspected reference. Prefer semantic primitives and short purposeful Bezier paths, clear paint order and sparse anchors at corners/extrema. Keep parts independently selectable and related parts meaningfully grouped; keep lettering in live native frames. Do not substitute generated bitmaps for vector work. Validate geometry and native preflight, render and visually inspect at target size. Fix recognition-bearing shape, overlap or proportion defects before decoration. Preserve unaffected IDs/content and the best previous version; stop unproductive repair loops. Optional reference or image generation requires actual user selection and provider authorization.

Read references/native-guide.md for the native command and output limits. Loading this skill is not authorization to generate or approve another batch.
