Choose the graphic scenario, finite coordinate system and output requirements before drawing. Use simple native primitives or short Bezier curves, explicit fill/stroke and stable semantic part names. Derive chart geometry from supplied values; do not invent data or labels. Keep icon strokes uniform and test at actual target size. Reuse approved palette/parts and keep live text independent. No empty paths, placeholders, external resources, scripts, raster disguise or unnecessary generation. For native print work, translate SVG concepts into the current engine catalog and editable document objects. Gradients, animation, masks, CSS theming, React/Vue and standalone SVG export are not implied; disclose unavailable features rather than silently flattening. Validate, render and inspect after focused corrections.

Read references/native-guide.md for the native command and output limits. Loading this skill is not authorization to generate or approve another batch.
