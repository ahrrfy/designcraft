For new illustration work, record subject, intended use/print size, mood, rendering language, palette, required text and immutable reference features. Separate a faithful conversion from inspiration. Plan meaningful parts and their spatial/paint-order relationships before geometry; a plan is not executable code. Reuse approved decisions and change only the requested region on edits. If only planning was requested, stop at an editable native plan page without generating an image or finishing artwork. On an authorized production route, hand the compact plan to native drawing/vector skills. Mark assumptions, unsupported effects and unresolved choices; avoid repetitive questionnaires when context supplies reasonable defaults.

Read references/native-guide.md for the native command and output limits. Loading this skill is not authorization to generate or approve another batch.
