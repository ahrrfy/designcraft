Create a brief math check that reveals reasoning about one learning objective. Use the teacher's grade, topic and supplied lesson; clarify only missing information that changes the items. Confirm a proposed focus if the request has not fixed it. Write 1-3 original items with age-appropriate language and a diagram when it clarifies the concept. For every distractor, explain a plausible reasoning path that reaches it. Prepare a clean student page and a separate teacher guide linking each observable response to a distinct next teaching step. Avoid scores and fixed ability labels. Read the completed items without the key: verify defensible answers, compute the actual quantities, and repair ambiguity or unreachable distractors. Require teacher pedagogy review before classroom use. Standards are verified only against a source actually supplied and read; otherwise mark them unverified. Learning Commons KG is optional and is not connected by this package. Never invent citations, API results, certification or endorsement.
