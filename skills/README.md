# Portable DesignCraft skills

25 importable data packages accompany the native AI production runtime. Import a
package folder from **AI Production and Skills → Skills**. The host validates the
command allowlist, parameters and native sample before automatic activation for a
matching task. A successful technical sample never approves a production batch.

| Packages | Purpose |
|---|---|
| `accepted-science-editorial` | Four original illustrated A4 science compositions: growth and sequencing, plant needs, plant parts and leaf rubbing, seed observation journal |
| `kg-oxford-cambridge-style` | Original curriculum architecture with ten editable page families; publisher names describe references, not endorsement or certification |
| Eight `kg-*` guidance packages | Vocabulary/story layout, CPA thinking, phonics/handwriting, sensory colour, workbook print, integrated language skills, projects and computing |
| `kg-international-curriculum-architect` | Suggested unit and lesson outlines, progression and connected activities; preserves the selected design profile and requires educator review |
| `native-editorial-variety` | Varied activity and information layouts within one series identity |
| Thirteen adapted illustration/STEM/lesson packages | Native alternatives to external SVG, image and teaching workflows, with pinned provenance and retained MIT/Apache notices where available |

The first and second requested GitHub skill batches retain their upstream text as
archival `assets/` only. The active instructions and original examples use native
DesignCraft commands. No upstream executables are installed or run. The
`native-stem-diagrams` alternative is original: the referenced upstream repository
had no clear license at the inspected commit, so its instructions/code are absent.

The eight portable KG guidance examples use original native templates. Local
publisher-reference character images, copied book art, private visual-review
history, generated trial files and absolute user paths are excluded. The accepted
science identity is described in portable prose and native geometry. Coloured
illustrations are generated by the selected provider and placed by the host in
editable frames; they are not flattened page images. User text, shapes, frame
geometry and crops remain editable; raster illustration pixels are replaceable.

`catalog.json` records SHA-256 for each packaged file. It is a distribution index,
not a trusted live registry: approval records, enabled state, credentials, job
checkpoints and spending ledgers belong to the user's protected local profile.
No pre-approved production authority or provider secret is distributed.

Shared image crops in the science profile require the AI11 native host. Use two
pages per batch for that profile. Every task pins exact skill revisions and stops
for human proof review before another batch. Native preflight must pass before
image spending or publication. Technical acceptance does not certify educational
accuracy, publisher similarity, printing hardware or actual provider charges.
