Use only with an accessible supplied image and an image-capable analysis route. Inspect actual pixels, dimensions, orientation, alpha, background and landmark positions; never infer content from a filename. Preserve canvas, branding, color relationships, lettering and whitespace unless a change was requested. Reconstruct recognition-bearing parts as native shapes/curves with stable labels and meaningful groups, not embedded raster or pixel-sized rectangles. Dense photos need an explicit fidelity/simplification decision. Render and compare at matching crop, scale and background; disclose approximation, font dependency and unverified features. Never claim automatic tracing or vision ran if it did not. Do not upload references or request paid generation merely to load this skill.

Read references/native-guide.md for the native command and output limits. Loading this skill is not authorization to generate or approve another batch.
