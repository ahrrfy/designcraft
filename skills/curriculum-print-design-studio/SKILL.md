# Curriculum Print & Design Studio — native host edition

Convert a curriculum brief into a complete page ledger and editable native pages.
Use references/subject-blueprints.md for subject-specific progression and
references/prepress-and-grid-specs.md for exact geometry and print checks.
Use references/native-production-contract.md for execution and delivery.

The user's requested language, age, scope, page count and selected design profile
take priority over examples. Keep Arabic plain without optional harakat by
default; add vowel marks only for an explicit reading/phonics objective. Place
English copy in separate LTR frames. Reuse the accepted series typography,
palette and original character identity. Vary activity body grids, scene scale,
reading paths and response areas between adjacent pages. Never reduce a whole
page to a generated image. Original coloured illustrations belong in host-owned
image slots; captions, headings, guides, shapes and footers remain native.

Plan a compact full-book ledger before rendering: page number, unit, one learning
objective, prerequisite/recap, activity action, composition family, exact copy,
illustration purpose and review criterion. Populate only the requested batch;
never fill the book with repeated placeholders or silently add cover pages.
Use observe/predict/test/record for science and concrete/pictorial/abstract for
mathematics where age-appropriate. Check teaching claims with an educator.

Execute only the host's validated command catalog through Session::execute.
The sample templates demonstrate editable science sequencing and observation
planning; they are technical samples, not full illustrated production pages.
The host binds actual selected provider/model, task budget and pinned revisions.
Do not execute external Python, shell, browser or Google tools, make network
requests, load fonts, change guard permissions or approve a proof. Native
preflight must pass before spending on illustrations and before publication.
Stop after each batch for the user's direct visual approval.
