# Production and delivery

1. Pin user scope and profile; build a complete non-overlapping page ledger.
2. Select relevant subject, layout, typography and prepress skills automatically.
3. Request bounded exact copy and illustration intentions for this batch only.
4. Compile validated native templates; run native geometry/text/glyph preflight.
5. Generate only needed original image sources; place in independent native frames.
6. Inspect actual composition, reading order, factual content, answer spaces and
   final export. Keep text, diagrams and furniture independently editable.
7. Save a new native document/export revision and usage report. Report measured
   time, provider tokens and estimated versus actual charges without guarantees.
8. Stop at human proof. Approval cannot be inferred from a sample, timeout or
   imported skill. Never print or generate the next batch without that authority.

Use the built-in curriculum blueprint for bounded sequencing. The supplied
external Python text-generator is not installed: it cannot drive native tools,
validate a final PDF or preserve live undo/history. No external executable is
needed. The original source folder is preserved untouched on this computer.
